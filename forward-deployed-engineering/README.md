# Forward Deployed Engineer Roadmap (Oct–Dec 2026) 💼

A rigorous 90-day curriculum designed to turn software and automation engineering skills into verifiable evidence for **Associate FDE**, **AI Deployment Engineer**, and **Solutions Engineer** roles.

---

## 🎯 High-Level Deliverables

| Deliverable | Description | Ships |
| :--- | :--- | :--- |
| **E1: Real Client Engagement** | Discovery → SOW → AI workflow wired into tools → go-live → handover with ROI measured | Nov 30 |
| **E2: Enterprise Reference Deployment** | Permission-aware RAG over Google Drive with SSO, audit logs, private-VPC infrastructure and security pack | Dec 19 |
| **Kit: FDE Field Kit** | Discovery question bank, SOW template, status-update template, security questionnaire answers, runbook, demo script | Ongoing |

---

## ⏱️ Daily Schedule & ML Plan Alignment

Runs in parallel with your ML plan (Days 1–92 match exactly):
- **Mon–Sat:** 90 min ML + 45 min FDE (5 min recall, 35 min do, 5 min log) = 2 h 15 min total
- **Sunday:** 90 min ML review + 15 min FDE touchpoint prep = 1 h 45 min total
- **Total FDE Commitment:** ~62.5 hours across the quarter.

### How ML & FDE Complement Each Other
- **Days 64–71:** ML RAG pipeline feeds directly into **E2**, adding enterprise permissions, SSO, and VPC infra.
- **Day 71:** ML evaluation harness becomes the customer acceptance test.
- **Days 76–77:** FastAPI & Docker skills speed up FDE deployments.
- **Days 89–92:** Dual job application search (AI Engineer + FDE).
