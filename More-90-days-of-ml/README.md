# More 90 Days of ML 🚀 (Days 93–182)

The advanced continuation of the 90 Days of ML curriculum, focusing on:
1. **Production Cloud Engineering & Infrastructure as Code (AWS, Terraform, ECS, CI/CD, pgvector)**
2. **Recommender Systems & Learning-to-Rank (LightGBM LambdaRank, NDCG, real-time feature caching)**
3. **High-Throughput LLM Systems (vLLM, 4-bit quantization, load testing with Locust, Langfuse, OWASP security guardrails)**
4. **Flagship Product ML (Oryzon feature in production with real users & A/B testing)**
5. **Open Source Contributions (Transformers, sentence-transformers, vLLM, scikit-learn)**
6. **Senior-Track Interview Preparation & Job Search**
