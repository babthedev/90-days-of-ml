# 90 Days of Machine Learning 🧠

A comprehensive daily curriculum, learning log, notes, and implementations for mastering Machine Learning and shipping production-grade AI systems in 90 days.

---

## 🎯 High-Level Overview

- **Phase 1 — October: Classical ML + FlyRank Foundations (Days 1–31)**  
  *Goal:* Train, validate, and explain classical models on real data; complete all 5 FlyRank foundation assignments by Oct 31.
  - **Gate 1:** Assignments 1–5 submitted.

- **Phase 2 — November: Capstone, Deep Learning, Transformers (Days 32–61)**  
  *Goal:* Submit FlyRank Capstone (P1) by Nov 9, build autograd/micrograd, train PyTorch vision models, and build a small GPT from scratch.
  - **Gate 2:** Capstone in, tiny GPT trained.

- **Phase 3 — December: LLM Engineering, Deployment, Job Launch (Days 62–92)**  
  *Goal:* Build & evaluate production RAG (P2), LoRA fine-tuning (P3), containerize with Docker/FastAPI, experiment tracking with MLflow, and send 15 targeted applications.
  - **Gate 3:** 15 applications sent, P2 live on Spaces.
