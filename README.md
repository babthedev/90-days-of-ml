# 90 Days of Machine Learning 🧠

A comprehensive daily log, notes, and implementations for mastering Machine Learning in 90 days.

## 📌 Structure
- **Phase 1: Foundations (Days 1–20)**
  - Linear Algebra, Calculus, Probability & Statistics
  - Python for Data Science (NumPy, Pandas, Matplotlib, Seaborn)
- **Phase 2: Classical Machine Learning (Days 21–50)**
  - Supervised Learning (Linear/Logistic Regression, Trees, SVMs, Ensembles)
  - Unsupervised Learning (K-Means, PCA, Clustering)
  - Model Evaluation & Feature Engineering
- **Phase 3: Deep Learning Foundations (Days 51–75)**
  - Neural Networks, Backpropagation, Optimization
  - PyTorch / TensorFlow
  - Computer Vision (CNNs) & NLP (RNNs, Transformers intro)
- **Phase 4: Advanced Topics & Projects (Days 76–90)**
  - LLMs, Fine-tuning, RAG
  - End-to-end ML deployment & portfolio projects
